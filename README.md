# lead-management-crm# Lead Management CRM

A full-stack Lead Management CRM built with React.js, Node.js, Express.js, and MongoDB.

## Features
- ✅ Add new leads/customers
- ✅ View all leads in dashboard
- ✅ Update lead status (New, Contacted, Qualified, Converted, Lost)
- ✅ Edit & Delete leads
- ✅ Search leads by name, email, or company
- ✅ Lead statistics dashboard (Bonus)
- ✅ Responsive design (Bonus)

## Tech Stack
- **Frontend:** React.js
- **Backend:** Node.js + Express.js
- **Database:** MongoDB
